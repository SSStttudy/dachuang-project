# B：面向非专业创作者的照片式交互导览低代码制作

状态：候选。

目标用户：讲解员、学生、展览组织者；是否真实需要自行制作，待访谈确认。
方案：导入地图和照片 → 标注区域 → 连接场景 → 配置知识卡与探索任务 → 预览导览。

研究问题：哪些编辑表达和错误提示能降低新手理解空间关系与任务逻辑的成本？
复用基础：Cocos 区域编辑扩展、场景模板、任务配置与播放端。
新增工作：摆脱明中都固定内容；统一项目配置；建立完整的制作、预览流程。

验证：同等培训后，让参与者分别使用原有配置流程与新工具完成同一任务；记录成功率、耗时、错误、求助及主观易用性。采用任务顺序平衡，降低学习效应。
风险：只有表单与拖拽功能，可能不足以形成研究贡献。应选定可测的交互改进。
首个小样：不修改业务代码，配置出第二个含 3—5 个地点的虚拟导览。
工作量判断：五项中工程基础复用较高，但独立通用编辑器仍需额外投入。
