# E：证据分层的古今对照交互与认知效果

状态：候选，专业资源待确认。

对象：文化遗产学习者。
问题：如何帮助参观者理解遗址空间，同时分清实物证据、文献依据与艺术推测？
方案：现状照片、经审核的复原表达和分层说明，在同一交互场景中对照呈现。
效果参考：照片场景与局部观察交互；历史复原内容须有独立资料依据。
开发范围：重新准备专业资料与素材，完成复原内容审阅、交互设计、认知题目和实验。

对照：普通图文、直接复原图、证据分层交互。
指标：空间理解、事实记忆、推测误认率；不能只测满意度。
风险：缺少可靠复原与专业审核；美术效果不能证明考古真实性。
启动条件：确认可获得足够史料及专业反馈；无此资源时暂缓。

## 需求分析

- 目标用户：文化遗产学习者，既需要理解遗址空间，又需要知道哪些是实物证据、哪些是艺术推测。
- 现有证据：文化遗产虚拟复原研究指出过于逼真会让人把推测当事实，主张区分现存证据、证据性复原与假设重建（E 组论文 1）；720 云已有同点位画面对比，但不涉及证据等级（见[竞品对比](../../02-案例与参考/论文与竞品/竞品调研/竞品对比.md)）。
- 待验证：目标学习者是否关注、能否理解证据分层信息，需以认知实验检验，而非主观满意度。

## 候选创新点

1. **证据—特征对应**：将每份史料对应到复原对象的具体特征（论文 2 的 Source Feature Matrix 思路），交互中可逐部分查看依据。
2. **确定性/推测的视觉编码对照**：比较边框、黑白、模糊等表达方式对“确定—推测”辨识的影响（论文 3）。
3. **以推测误认率为核心的认知评测**：结合空间理解与事实记忆，而非只测满意度。

最小小样：选取单一建筑局部（如一处门殿），呈现现状照片、两种复原表达与证据卡，组织小样本认知测试。若无法获得可靠史料与专业审核渠道，本方向暂缓。
