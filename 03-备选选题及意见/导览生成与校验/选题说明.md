# A：空间约束驱动的交互式导览生成与校验

状态：候选；未定题。

## 问题与对象

面向文化遗产导览制作人员，研究如何把已有地图、照片、资料和必要人工标注转化为可运行的虚拟导览，减少无效连接、不可达目标与任务依赖错误。真实制作需求仍需访谈。

## 候选方案

输入：地图、照片、来源资料、人工确认的地点与连接关系、导览主题。
输出：可编辑的场景与任务配置、讲解来源、校验报告和可播放样例。
流程：检索资料 → 生成配置 → 检查引用、连通性和任务依赖 → 根据错误反馈修正 → 人工确认 → 播放。
Agent 负责调用工具与修正方案；具体模型、框架、接口在定题与试验后确定。

## 拟研究增量

比较加入空间和任务约束后，生成结果的有效性与人工修订成本是否改善。不能仅以调用大模型作为创新结论。

## 实现范围

数据结构、制作界面、校验工具和播放端均按选题需要重新设计；技术栈待定。循迹中都仅提供交互效果参考，代码、素材和实现方案均不纳入新项目。第一版不包含真实定位导航、3D 重建或自动历史复原。
先完成一个小地图端到端流程，再用第二场景验证迁移；避免先开发完整平台。

## 评估

对照：人工制作、无检查反馈的直接生成、带校验反馈的生成。
指标：有效配置比例、任务可完成率、人工修改次数、总制作时间、模型耗时与调用成本。
样本需覆盖断连、无效目标、循环依赖与缺失资料；正确性标签由独立检查或人工复核确定，不能只由生成模型自评。

## 需求分析

- 目标用户与场景：文化遗产导览制作人员（教师、讲解员、学生团队），在地图、照片与资料齐备后制作可运行的虚拟导览。
- 痛点的现有证据：国创平台 2025—2026 年同类立项普遍描述“讲解碎片化、千人一面”，但均未报告制作期错误率（见[已核实立项参考](../../02-案例与参考/立项选题/已核实选题.md)）；竞品资料中没有工具检查断连、不可达目标与任务依赖（见[竞品对比](../../02-案例与参考/论文与竞品/竞品调研/竞品对比.md)）。
- 内部证据待整理：团队在循迹中都相关制作中的连接与任务配置自查经历，可整理为时间记录，但不能代替对外部真实制作者的访谈。
- 待验证：访谈至少 3 名潜在制作者，统计其实际制作方式、返工次数与最常见错误。

## 候选创新点

1. **分层校验与定位反馈**：检查分为格式、连通性、任务依赖与引用四层，校验器返回具体错误位置与原因，驱动再生成（与 PlanGEN 的通用规划、LLM+P 的规划器求解形成差异，见 A 组[论文清单](../../02-案例与参考/论文与竞品/A-导览生成与校验/论文清单.md)）。
2. **需求忠实度核查**：修正后比对原始约束是否被删改或弱化（对应论文 4 所研究的“为可解而改需求”问题）。
3. **以人工修订成本为核心的评测协议**：有效配置比例、修改次数与总制作时间并重，而非只看能否生成。

说明：单纯“用大模型生成导览”在 2025—2026 年立项中已密集出现，不构成创新；增量必须来自校验反馈闭环及其效果证据。

## 实现难度：高

| 模块 | 难度 | 说明 |
| --- | --- | --- |
| 场景与任务数据结构 | 中高 | 需同时表达地点、连接、任务依赖与资料引用 |
| 生成与模型对接 | 中 | 可基于现有 Agent 或工作流方式 |
| 四类校验器 | 高 | 通用约束表达与跨场景迁移是主要成本 |
| 制作界面与播放端 | 中高 | 两端均需投入 |
| 评测样本与标签 | 中 | 需构造断连、无效目标、循环依赖、缺资料样本 |

最小小样：5—8 个地点，先以表格或 JSON 作为输入（暂不做编辑器），仅实现连通性与任务依赖两类检查，对比“直接生成”在错误数与人工修改次数上的差异；通过后再扩展检查层与界面。

## 意见与待办

讨论重点：生成与校验能否形成明确的研究增量，以及完整制作流程的开发成本。
待办：制作数据抽象与检查器小样；访问潜在创作者；核对相关生成研究。
