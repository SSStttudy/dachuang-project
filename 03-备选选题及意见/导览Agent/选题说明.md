# C：融合场景状态与史料证据的导览智能体

状态：候选。

对象：虚拟参观者。
问题：普通问答不一定理解当前地点、已完成任务与可用时间；本方向研究回答和导览行动如何同时受这些条件约束。
方案：将已审阅资料、当前位置、已访问内容和用户偏好提供给智能体，通过受限工具选择下一站、打开知识卡、给出有出处的解释。
边界：首版在虚拟地图内工作，不承诺真实定位、景区实时状态或自由操作任意场景。

示例任务：“还有五分钟，想了解宫殿布局。”系统给出可达、可完成的短导览；资料不足时说明无法确定。

开发范围：重新设计场景与任务状态、知识展示、资料检索、行动检查和评测集；不引入效果参考项目的代码或素材。
对照：固定导览、只检索资料的问答、加入场景状态的智能体。
指标：证据支持率、行动有效率、任务完成率、时间约束满足情况、响应时间与成本。
风险：可聊天不等于可研究；史料标签需人工核验。先做小规模任务集再扩展功能。

## 需求分析

- 目标用户：虚拟参观者，在游览中随时提问，希望系统结合当前位置、进度与剩余时间作答。
- 现有证据：三毛游等已上线 AI 导游，说明需求被市场认可，也意味着“可聊天的导览”不新；需通过实操收集其在位置、时间、任务相关问题上的失败案例（见[竞品对比](../../02-案例与参考/论文与竞品/竞品调研/竞品对比.md)）。
- 待验证：构造“还有五分钟，想了解宫殿布局”一类任务式问题，检验纯问答与状态感知回答的差异是否显著。

## 候选创新点

1. **场景状态约束的受限工具调用**：位置、已访问内容、任务进度与剩余时间作为显式状态，行动经合法性检查后执行（在 ReAct 工具调用之外增加状态与行动约束，见 C 组论文 2）。
2. **有出处的回答与显式拒答**：回答附资料来源，资料不足或行动不可达时明确说明，以证据支持率评测（论文 1 的 RAG 不具备位置与行动感知）。
3. **回答与行动一致性的三对照实验**：固定导览 / 纯资料问答 / 场景状态智能体。

## 实现难度：中高

| 模块 | 难度 | 说明 |
| --- | --- | --- |
| 场景与任务状态机 | 中高 | 需与导览数据结构一致 |
| 资料检索与出处标注 | 中 | 史料标签需人工核验 |
| 工具调用与行动检查 | 中高 | 非法动作拦截与时间约束判断 |
| 评测集 | 高 | 问题、参考回答与标签工作量大，是结论可信的前提 |

最小小样：单场景 8—10 个地点、20—30 个任务式问题，先跑通三对照；记录响应时间、模型调用成本与证据支持率，再扩展场景。
