# C：融合场景状态与史料证据的导览智能体

状态：候选。

对象：虚拟参观者。
问题：普通问答不一定理解当前地点、已完成任务与可用时间；本方向研究回答和导览行动如何同时受这些条件约束。
方案：将已审阅资料、当前位置、已访问内容和用户偏好提供给智能体，通过受限工具选择下一站、打开知识卡、给出有出处的解释。
边界：首版在虚拟地图内工作，不承诺真实定位、景区实时状态或自由操作任意场景。

示例任务：“还有五分钟，想了解宫殿布局。”系统给出可达、可完成的短导览；资料不足时说明无法确定。

开发范围：重新设计场景与任务状态、知识展示、资料检索、行动检查和评测集；不引入效果参考项目的代码或素材。
对照：固定导览、只检索资料的问答、加入场景状态的智能体。
指标：证据支持率、行动有效率、任务完成率、时间约束满足情况、响应时间与成本。
风险：可聊天不等于可研究；史料标签需人工核验。先做小规模任务集再扩展功能。
