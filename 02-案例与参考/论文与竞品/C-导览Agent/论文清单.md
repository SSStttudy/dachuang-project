# C：导览 Agent——论文清单

更新时间：2026-09-28

## 论文

### 1. Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

- 作者：Lewis et al.
- 年份：2020
- 链接：https://arxiv.org/abs/2005.11401
- 做了什么：把语言模型与外部知识库结合，即 RAG。
- 对本项目有用：
  - 导览知识应从资料中检索，而不是只靠模型记忆；
  - 可以评价回答有没有资料依据。
- 不足：
  - RAG 不知道当前位置；
  - 也不知道某个动作当前能不能执行。

### 2. ReAct: Synergizing Reasoning and Acting in Language Models

- 作者：Yao et al.
- 发表：ICLR 2023
- 链接：https://arxiv.org/abs/2210.03629
- 做了什么：让模型一边思考，一边调用工具获取信息或执行动作。
- 对本项目有用：
  - Agent 可以调用“当前位置”“可达地点”“打开知识卡”等工具；
  - 工具调用过程可以被记录和检查。
- 不足：
  - ReAct 本身不保证动作合法；
  - 仍然需要额外规则限制 Agent。

### 3. An Embodied AR Navigation Agent: Integrating BIM with Retrieval-Augmented Generation for Language Guidance

- 作者：Yang et al.
- 发表：ISMAR 2025
- 预印本：https://arxiv.org/abs/2508.16602
- 做了什么：把建筑空间数据、多 Agent RAG 和 AR 导航结合。
- 用户研究：20 名参与者，论文报告 SUS 80.5。
- 对本项目有用：
  - 空间数据和资料检索可以结合；
  - 可以同时评价回答和行动。
- 不足：
  - 使用 BIM 和 AR，资源要求高；
  - “RAG + Agent + 空间数据”已经不是新点。
