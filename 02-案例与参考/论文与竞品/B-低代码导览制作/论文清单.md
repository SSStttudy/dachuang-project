# B：低代码导览制作——论文清单

更新时间：2026-09-28

## 论文

### 1. End-user development, end-user programming and end-user software engineering: A systematic mapping study

- 作者：Barricelli, Cassano, Fogli, Piccinno
- 发表：Journal of Systems and Software, 2019
- DOI：https://doi.org/10.1016/j.jss.2018.11.041
- 做了什么：系统梳理 165 篇终端用户开发研究。
- 对本项目有用：
  - 非程序员自己制作数字内容是成熟研究方向；
  - 工具是否好用必须通过真实任务评价。
- 不足：
  - 不能直接告诉我们导览编辑器应该怎么设计；
  - 拖拽、表单和可视化本身已经不是创新。

### 2. User-Centered Requirements for an Authoring Tool in XR Cultural Heritage

- 发表：Mensch und Computer 2026
- DOI：https://doi.org/10.1145/3820253.3831392
- 做了什么：采访文化遗产领域的策展人、历史研究者等专业人员。
- 主要发现：
  - 新手希望快速上手；
  - 熟练用户希望可以细调；
  - 不同角色的需求差异很大。
- 对本项目有用：
  - 可以尝试“新手模式 + 高级模式”；
  - 目标用户不能写得太笼统。
- 不足：
  - 论文中的专业用户不等于本项目未来用户。

### 3. Design, implementation, and user evaluation of a no code 3D serious game authoring tool for cultural heritage education

- 作者：Abdulrazic, Sanzana, Ng
- 发表：Discover Education, 2026
- DOI：https://doi.org/10.1007/s44217-026-01162-0
- 做了什么：开发无代码 3D 文化遗产创作工具，并进行多轮用户测试。
- 主要发现：
  - “无代码”并不自动等于“好用”；
  - 素材和任务类型也会限制创作；
  - 用户觉得有趣，不等于学习效果一定更好。
- 对本项目有用：
  - 用户实验不能只问满意度；
  - 应记录时间、错误和求助次数。
- 不足：
  - 研究对象主要是 3D serious game，而不是照片式导览。
