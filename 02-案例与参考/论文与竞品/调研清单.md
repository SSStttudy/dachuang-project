# 论文与竞品调研清单

状态：文献方向 A—E 已建立首轮论文清单；竞品已完成首轮资料梳理，见[竞品对比](竞品调研/竞品对比.md)。系统文献综述与竞品实操测评尚未开展。以下检索计划不是已证实的技术结论。

## 文献方向

| 方向 | 检索词 | 要回答的问题 |
| --- | --- | --- |
| 导览生成与校验 | interactive tour authoring; constraint-guided generation; tool-using agents | 现有方法如何保证生成结果可执行？ |
| 自动编排 | personalized tour planning; orienteering problem; narrative planning | 时间、兴趣和任务依赖如何同时建模？ |
| 有依据的讲解 | grounded dialogue; retrieval augmented generation; cultural heritage | 来源正确性、场景一致性怎么评测？ |
| 创作交互 | end-user development; low-code authoring; usability evaluation | 非专业作者的成本主要在哪里？ |
| 历史认知 | heritage visualization; uncertainty communication | 如何区分证据与艺术推测？ |

每个优先候选先精读 3—5 篇相关原始论文，记录任务、输入输出、数据、基线、指标和不足，再归纳本项目增量。

## 竞品类别

首轮资料梳理结果见[竞品对比](竞品调研/竞品对比.md)，覆盖：

- 图文与地图热点导览工具、全景漫游 SaaS（720 云、酷雷曼等）。
- 虚拟展览、数字展厅与全景漫游制作工具（Pano2VR、krpano、ThingJS 等）。
- 游戏引擎内的场景与任务编辑工具。
- 大模型工作流、内容生成与智能讲解产品（三毛游 AI 导游、如视 Argus Museum、腾讯文旅等）。

统一制作一个小样：5 个地点、2 条路线、3 个交互任务、1 处无效连接。记录工具版本、实际步骤、耗时、错误检查能力、发布结果、费用来源及限制。不以营销页代替实际使用结果。
