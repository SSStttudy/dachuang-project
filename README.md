# 大创项目协作仓库

[dachuang-project](https://github.com/SSStttudy/dachuang-project) 用于合肥工业大学计算机科学与技术专业大创项目的团队协作，涵盖资料调研、选题讨论及后续项目工作。

当前处于选题阶段，项目名称、研究方向与技术方案均未确定。计划于 2026 年 11 月前后准备下一年度校内申报，具体批次与时间以学校和学院通知为准。

## 当前工作

- 整理大创政策、申报要求和相关案例。
- 收集备选选题，讨论需求、创新点与实现难度。
- 开展文献与竞品调研，记录导师意见与讨论结论。
- 根据调研结果确定选题、团队分工与后续计划。

## 参与协作

1. 阅读 [选题对比](03-备选选题及意见/选题对比.md)，了解各候选方向。
2. 新增选题或提出意见时，说明问题、依据与待验证事项。
3. 修改通过分支和 Pull Request 提交，注明变更内容与需要讨论的问题。
4. 选题结论经讨论确认后，更新相应选题页与决策记录。

详细约定见 [协作规范](CONTRIBUTING.md)。
