# 大创项目协作仓库

[dachuang-project](https://github.com/SSStttudy/dachuang-project) 是大创项目的协作仓库，覆盖选题、申报、研发、实验、竞赛和结题全过程。当前处于选题阶段，研究方向尚未确定。

## 当前状态

- 学校与专业：合肥工业大学，计算机科学与技术。
- 当前阶段：选题调研；尚未定题、未确认导师与团队。
- 目标：2026 年 11 月前后准备校内申报，面向下一年度项目，争取国家级与竞赛成果。
- 正式批次、截止日、资格与模板：待下一轮学校及学院通知确认。
- 现有基础：明中都 Cocos 项目；只是可复用基础，不限定最终研究方向。

## 从这里开始

1. 阅读 [政策与时间节点](01-大创政策与申报/时间节点.md)。
2. 比较 [备选选题](03-备选选题及意见/选题对比.md)，在各选题页补充意见。
3. 查看 [已有工程分析](04-现有项目基础/功能与技术梳理.md)。
4. 按 [近期任务](05-讨论与决策/近期任务.md) 收集证据，再决定题目。

## 协作约定

- 参考资料注明来源、发布日期、核验日期和适用批次。
- 立项、入围、获奖分开记录；建议和预期指标不写成已实现成果。
- 选题状态使用：待调研 / 调研中 / 候选 / 已选定 / 暂缓；当前五项均为候选。
- 导师意见注明反馈日期与适用选题；团队决定记录理由与日期，保留备选方向的评估过程。
- 原始个人信息、令牌、未脱敏问卷不提交。现有 Cocos 工程暂未迁移。
- 正式申报前复核学校现行政策、素材权属与成果署名。
